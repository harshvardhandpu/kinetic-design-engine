# 24 — v0.1 Roadmap (Phase-2 Recommendation)

Phase 1 produced research + architecture + schemas. Phase 2 must PROVE the
loop, not accumulate features.

## The proof criterion (task §35)

Phase 2 succeeds only if this full loop works once, end-to-end, on a real
playground project:

```
Hermes installs effect → renders page → target visually identified →
feedback maps to correct source → Hermes modifies it → page still works →
quality checks pass
```

Animation impressiveness is NOT the criterion.

## Recommended Phase-2 scope

| Item | Target | Notes |
|---|---|---|
| Playground | 1 small app (stack per `23` D5 decision) with ≥2 routes of different surface types (decide-learn landing + configure/settings page) | proves surface gating, not just hero tricks |
| Primitives | 5–8, evidence-anchored: `split-characters`, `pixel-reveal` (dom variant), `stack-deck`, `particle-sphere` (canvas2d), `marquee`, `split-text-words`, (+) `scramble-text`, `toggle-morph` | each with manifest, tokens, reduced-motion variant, no-JS state, motion handle |
| Recipes | 2–3: `kinetic-typography-hero`, `swiss-pixel-transition`, (+) `bento-deck-nav` | protagonist rule enforced |
| Registry installer | resolve → conflict check → copy → token map → receipt; update-with-diff stub | script-level, no package |
| Framework adapter | ONE primary (`17`/`23` D5) + vanilla CSS/WAAPI shared core | |
| Scanner | framework detect, token extraction, surface classification, three-zone map on the playground | `10` Phase-2 scope |
| Inspector | dev-only mount, hover/click/annotate, kinetic ids in payload, pause animations, file-drop export | agentation-shaped (`11`) |
| Motion inspector | pause/resume/restart + progress + token-resolved values for the proof primitives | `12` minimal |
| Evaluator | overflow-x, console errors, contrast, focus states, reduced-motion check, token discipline, 3 slop detectors | `13` minimal |
| Showcase | one hero built via recipe install on the playground landing | the loop's demo surface |
| Hermes integration | SKILL.md draft tested against playground ONLY — not installed in live Hermes | task §0 constraint |

## Explicitly deferred (v1+)

Second framework adapter · WebGL/WebGPU rungs · scrub/slow-motion inspector ·
MCP/webhook delivery · full evaluator catalog · learning-loop persistence
adapter · registry HTTP serving · Vue/Astro adapters · K5 research items.

## Sequencing suggestion

1. Schemas frozen + validation tests (this repo's first "build").
2. Shared vanilla core + 3 primitives (split-characters, pixel-reveal, marquee)
   with manifests — proves registry contract before framework glue.
3. Installer + receipt + kinetic ids.
4. Playground + primary adapter + remaining primitives + recipes.
5. Inspector + feedback file format + resolver (kinetic-id rung first).
6. Evaluator minimal + quality gates + regression baseline.
7. Full-loop rehearsal → record the evidence trail → Phase-2 report.

## Risks carried into Phase 2 (from final report)

- Infra: canonical host workspace mount must exist before Phase 2 writes
  (README §Infrastructure note).
- Visual verification: text-only model blocks screenshot-level QA; pair the
  Phase-2 loop with DOM-metric evaluation (already primary) and schedule
  vision-capable review passes for aesthetic gates.
- Scope creep: the 12-item table above is the whole scope; additions require
  removing something of equal size.
